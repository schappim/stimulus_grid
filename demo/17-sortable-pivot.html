17 — Sortable pivot columns

Click any pivot column header to sort sibling group rows by that aggregate — ascending, then descending, then off. Shift-click to add to a multi-sort. The synthetic (All) totals row stays pinned at the top no matter the sort. Try it with the country × sport pivot below: click Swimming to surface the swimming-heaviest nations.

Country Sport Athlete Age Gold Silver Bronze
no sort
How it works: pivot result columns are synthetic — built fresh from each row's __pivotValues. The sortModel can carry one of those synthetic field ids; buildPivotModel then sorts sibling group nodes by their aggregate value at each tree level. The (All) totals row is emitted outside the tree walk so it stays put.
