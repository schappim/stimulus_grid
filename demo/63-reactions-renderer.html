63 — Reactions renderer (Slack / Linear style)

Strip of emoji + count chips. Accepts either an object ({ '👍': 3, '❤️': 1 }) or an array ([['👍', 3], ['❤️', 1]]). Zero-count entries are dropped automatically.

Sorted by count desc by default — pass sort: 'order' on the renderer to preserve the input order (e.g. when chronology matters: first reaction → leftmost chip).
