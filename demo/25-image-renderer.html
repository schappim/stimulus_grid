25 — Image renderer

Inline thumbnails — pass the URL as the cell value; the renderer handles loading="lazy", sensible alt text (from row[altField]), and rounded corners. Pass { clickToZoom: true } for a lightweight click-to-zoom overlay (no library, closes on click / Escape). Three pre-registered variants below: default 36px square thumbnails, a 56px rounded avatar-style column, and a 36px click-to-zoom product thumbnail.
