29 — Mask renderer

Mask sensitive values for at-a-glance display: credit cards as •••• •••• •••• 4242, phones as ••• ••• 9999, emails as a••••@example.com. Built-in format presets cover the common shapes; a generic { showFirst, showLast, char } config covers everything else.

Cardholder Card Card (BIN) Phone Email API token
Presets used here: mask({ format: 'cc-last4' }), mask({ format: 'cc-bin-last4' }), mask({ format: 'phone-last4' }), mask({ format: 'email' }), and a generic mask({ showFirst: 4, showLast: 4 }) for the API token. The mask character is • by default; pass { char: '*' } for asterisks.
