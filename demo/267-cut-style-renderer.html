267 — Cut style

The keyway designator that tells the bench which jaws and clamp to set. Laser (HU64, HU100, NSN14) is sidewinder; ridge (TOY43, TOY40) is the classic stair-cut; dimple (TIBBE) is Ford UK.

Vehicle Cut style Kind

Silhouettes are not the actual milling profile — they're a visual distinction so a tech doesn't grab the wrong clamp set for a TOY43 when an HU64 was queued.
