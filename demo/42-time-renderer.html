42 — Time renderer (HH:MM[:SS])

Time-of-day-only sibling to date / datetime. Accepts "HH:MM", "HH:MM:SS", a full ISO timestamp, a JavaScript Date, or a number of seconds since midnight. Three columns show 24h, 12h, and 12h+seconds variants.

Appointment Start (24h) Start (12h) Duration Logged at
Inputs accepted (top → bottom of the demo): "09:30", "14:00:00", Date object, "2026-05-25T11:45:18Z", and seconds-since-midnight as a plain number for the Duration column.
