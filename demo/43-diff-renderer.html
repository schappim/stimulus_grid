43 — Diff renderer (old → new)

Audit log columns where the cell value is the before/after pair. Accepts { from, to }, [from, to], or a plain "old → new" string. Inline form is one line; pass style: 'stacked' for the vertically stacked layout.

Field Change (inline) Change (stacked) Actor When
One-sided diffs: a null from renders as a green addition prefixed with +; a null to renders as a red removal prefixed with −. Cleaner than "null → new" in an audit log.
