47 — Rating renderer (configurable icon)

The generic sibling of star-rating. Hearts and stars use the same fractional-fill engine; thumb is binary (up / down / neutral); smiley picks a face from a 1-N scale; NPS bands a 0-10 score into Detractor / Passive / Promoter colours.

Customer response Stars Hearts Thumb CSAT NPS
Half-fills: stars and hearts both support fractional values (default precision: 0.5). The partial glyph is rendered as a grey silhouette behind a coloured silhouette clipped to the fractional width — same recipe as star-rating, so any precision (halves, quarters, tenths) renders cleanly.

Editing: double-click any rating cell to edit it inline. Stars / hearts accept fractional values (try 3.5); thumb takes -1 / 0 / 1; smiley wants 1-5; NPS wants 0-10. The glyph re-renders live on commit.
