47 — Rating renderer (in-cell direct editing)

Each cell renders the full picker (stars / hearts / thumb / smiley / NPS) inline. Click any glyph or button to update the row — no double-click, no edit mode. Clicks commit immediately through api.applyTransaction(...).

Customer response Stars Hearts Thumb CSAT NPS
How the wiring works: a single registerRenderer per rating kind returns a clickable DOM tree. Each click-target carries data-value; a delegated handler on the wrapper reads it and calls api.applyTransaction({ update: [{ id, [field]: value }] }). The grid then re-renders the row with the new value.
