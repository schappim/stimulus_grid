47 — Rating renderer (with custom cell editors)

Stars / hearts / thumb / smiley / NPS each pair their renderer with a bespoke custom cell editor (AG-Grid-style), wired up through the grid's existing cellEditor template path + a Stimulus controller that owns the interactive UI. Double-click any cell to see it.

Customer response Stars Hearts Thumb CSAT NPS
How the wiring works: each editor is a <template> the grid clones into the cell on edit. The template carries data-controller="rating-editor", so Stimulus connects a small controller that builds the interactive UI and writes the selected value to a hidden data-editor-input field — that's the field the grid reads back when editing finishes (Enter / Tab / blur).
