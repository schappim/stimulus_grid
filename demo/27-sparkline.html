27 — Sparkline

Mini SVG line / area / bar chart per row, fed from a numeric array cell value. Auto-scales the y-axis to [min, max] across the data (or pass baseline: 0 to lock the minimum at zero — better for "did we go up from nothing?" stories). Pure SVG, no library, ~40 lines of renderer code.

Metric Now Trend (30d) Area Bar (weekly) Errors vs prev.
Variants: the Area column is sparkline({ type: 'area' }), Bar is sparkline({ type: 'bar', baseline: 0 }), Errors is sparkline({ color: 'red', type: 'area' }). Pass any palette key (blue, green, red, orange, purple, pink, gray) or a raw CSS colour. The cell value is just an array of numbers — pre-aggregated server-side, or sliced from a longer time series client-side.
