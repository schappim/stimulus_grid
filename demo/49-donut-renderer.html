49 — Donut renderer

Single-percentage donut chart — the circular sibling of progress-bar. Painted via stroke-dasharray from 12 o'clock clockwise so 25% lights up the top-right quadrant. Defaults embed the number inside the ring; pass inline: true for a side-by-side donut + label layout.

Goal Donut Blue Inline label Large Raw %
Palette: same palette tokens as sparkline — blue, green, red, orange, purple, pink, gray. Or pass any CSS colour string.

Editing: double-click any donut cell to edit its value — the SVG re-renders live on commit. Each column has its own field (the grid keys columns by field, so a single source field can't drive multiple columns — each donut gets its own clone of the percentage instead).
