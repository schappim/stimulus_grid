55 — Units renderer

Intl.NumberFormat({ style: 'unit' }) wrapped in a cell renderer. Locale-aware: switching browser language updates spacing and unit labels. Supports the full CLDR unit set — kilometer, mile, celsius, fahrenheit, kilogram, pound, liter, second, gigabyte, …

Localised: the renderer respects the locale option per registration; default (omitted) uses the browser's locale. Try units({ unit: 'celsius', locale: 'fr-FR' }) to see French formatting ("23 °C" with a hard space).
