67 — Empty placeholder renderer

Replaces null / undefined / empty / "N/A" cell values with a styled muted placeholder — useful when a column needs to communicate "intentionally blank" rather than "render-skipped".

Customer Email Phone Tax ID
The Tax-ID column shows what happens when the data contains common "no value" tokens (N/A, null, None, -) — the renderer recognises these and swaps them for the configured placeholder.
