15 — Right-click column menu & persisted state

Right-click any column header for quick actions: pin / autosize / group by / pivot by / aggregate / hide. The grid also has data-grid-persist-key-value="demo-15", so every change you make — sort, filter, pin, hide, group, pivot, value aggregations, the pinned bottom row toggle — round-trips through localStorage. Reload the page and your layout sticks.
