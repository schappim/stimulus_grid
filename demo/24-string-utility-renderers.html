24 — Truncate & copyable

Two string utilities. truncate caps long text at the cell width with an ellipsis and stashes the full value in title= so users can hover for the rest (pass {chars: 60} to clip by character count instead). copyable renders the value plus a tiny copy-to-clipboard button that shows on row hover; click and it briefly swaps to a check mark.

Hover any long Customer note or Address cell and the full value pops up in a browser tooltip.
