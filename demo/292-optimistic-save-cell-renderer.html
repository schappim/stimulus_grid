292 — Optimistic save state per cell

Edit any cell — the bottom edge flashes blue while the (simulated) save is in flight, green when it lands, red if the server rejects. Cells in error state are clickable to retry. Crucially the cell stays editable the whole time — we never block input on save.

Job # Customer Tech Hrs Note

State is tracked in a parallel Map keyed by rowId:colId (not in the row data) — that way it doesn't survive a row re-fetch, which is the right behaviour for "save in flight" UI.
