30 — Highlight (quick-filter matches)

Wraps matches of the grid's active quickFilter in <mark> tags so users see why a row was matched — not just that it was. The renderer reads the live filter via the api passed into every renderer call, so typing in the search box repaints highlights instantly without any wiring on your side.

How it works: the highlight renderer reads api.getQuickFilter() from the renderer context. When the grid's quickFilter changes, every row re-renders → the renderer re-runs → matches re-wrap. Case-insensitive by default; pass { caseSensitive: true } for case-sensitive. Pass { query: '…' } to highlight a fixed string regardless of the filter.
