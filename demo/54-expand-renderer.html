54 — Expand renderer

Long-text cells with a click-to-expand toggle. Different from truncate (hover for full value) and multi-line (preserves newlines + optional line-clamp). Use it when descriptions are too long for the row height but the reader sometimes wants the full text right there.

Article Summary (chars=140) Summary (lines=2)
Two modes: chars: N clips by character count (clean for paragraphs); lines: N CSS-clamps at N visible lines (preserves layout — needs newlines in the source to actually trigger the clamp). Both render plain pass-through for values short enough to fit.
