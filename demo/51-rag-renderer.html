51 — RAG renderer (red / amber / green dot)

Single status dot — pure traffic-light signal. Different shape from statusPill (labelled pill) and boolean (binary check/X). Use it when the column header is the label and the cell just needs to say "good / iffy / bad" at a glance.

Project Scope Schedule Budget Quality Error rate %
Two value paths: (1) literal tokens — 'red' / 'amber' / 'green' or any of the recognised synonyms (r/a/g, critical/warn/ok, high/medium/low, detractor/passive/promoter); (2) numeric values with thresholds: [redMax, amberMax]. inverted: true flips the mapping for "lower is better" columns like the Error rate column here.
