203 — Today's jobs (mobile)

A field-tech screen built on the renderers from 143–199. Desktop shows a seven-column dispatcher table (status, arrival, address, travel, callout, tech, vehicle). At narrow widths the grid collapses to a single tap-friendly job card, paging is replaced by infinite scroll, rows are swipeable for quick actions (left to invoice/complete, right to call/navigate), and a sticky bottom bar exposes the primary verbs.

How it works: a single matchMedia('(max-width: 640px)') listener flips data-mode on the grid and toggles column visibility via gridApi.setColumnVisible. The card column uses a <template> renderer that flattens the same row data into a two-line tap target — the desktop columns keep using the actual tradie renderers (job-status, arrival-window, suburb-postcode-au, travel-time, callout-fee, rego-plate), so this demo is a real composition test of the 143–199 set.

Swipe actions: on mobile, a single touch handler tracks touchstart/touchmove/touchend on the card cell. Horizontal drag past 60px snaps the row open to one of two action drawers (Invoice/Complete on the left, Call/Navigate on the right). Tap elsewhere or scroll vertically and the row snaps back. No native bridge required.

Bottom action bar: fixed-position, respects env(safe-area-inset-bottom) for iPhone home-indicator clearance, and reflects multi-row selection — pick a few jobs and the verbs apply in bulk.
