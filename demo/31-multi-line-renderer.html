31 — Multi-line renderer

Preserves \n newlines in the cell so notes / descriptions / commit messages don't collapse to a single line. Pass { lines: N } to clamp at N lines with an ellipsis — the full value still sits in title= for hover. Set data-grid-row-height-value on the grid wide enough for your max line count.

Variants: the middle column uses the bare multi-line registration (no clamp). The right column is multi-line({ lines: 3 }) — the renderer drops in a -webkit-line-clamp at 3 with the full message in title= so users can hover for the rest. Both columns are editable; commit edits restore the rendered newlines.
