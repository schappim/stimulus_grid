303 — Spare-key cabinet location

Where the off-site spares physically live. Three pieces of address: the cabinet room, the cabinet ID, and the colour-coded hook number. Beats "front office somewhere" when the tech who keyed the system has gone home for the night.

Key Cabinet location Custodian

The hook colour usually mirrors the master-key system colour code (often green = sub-master, red = grand master, amber = service keys, blue = guest). Keep colour + number together so a tech can't grab the wrong tag.
