40 — Linked-record renderer

Airtable / Notion-style FK chip — cell value is the foreign key, the renderer resolves it to a display name (+ optional thumb, tint, and outbound link) via a lookup function. Projects uses multiple: true to render a chip per linked project.

Task Owner Projects Status
Lookup contract: lookup(value, row) returns { name, thumb?, color?, href? }. The chip is rendered as an <a> when an href is provided (opens in a new tab) and as an inert <span> otherwise. color tints the chip background.
