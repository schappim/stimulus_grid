26 — Color swatch

Coloured chip + label. The cell value is the colour (any CSS-valid value — hex, rgb(), hsl(), named, even oklch()). Variants: circle (default) or square chip, sized to taste; label: 'name' reads the friendly name from another row field; showLabel: false gives a chip-only column for dense palette previews.

Token Hex Named Square Chip Used for
Variants: the Named column is colorSwatch({ label: 'name' }) — pulls the friendly name from row.name instead of the hex code. The Square column is colorSwatch({ shape: 'square' }). The Chip column is colorSwatch({ showLabel: false, size: 22 }) — chip-only, perfect for palette overview columns.
