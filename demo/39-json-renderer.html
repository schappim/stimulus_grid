39 — JSON renderer

Audit-log payloads, API responses, webhook bodies. Collapsed cells show a one-line summary of the first few keys; click the triangle to expand into a syntax-highlighted indented view. Strings, numbers, booleans, and nulls each get their own colour band.

Event When Payload Actor
Tip: the renderer accepts either a parsed object or a JSON string — anything that doesn't parse as valid JSON falls through to a plain-text render. Scalars (numbers / booleans / nulls) render in their syntax-highlighted colour without the expand control.
