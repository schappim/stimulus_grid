28 — Heatmap cell

Colour-grade the cell background on a numeric scale — green low → yellow mid → red high (or any two/three-stop palette you pass in). Auto-picks readable text colour (dark on light fills, white on dark) so the value stays legible. Pass inverted: true for "lower is better" columns (error rate, churn, latency).

Region Utilisation % Error rate % p95 (ms) CSAT Burn %
Variants: each column registers its own heatmap({...}) with the right min/max + palette. Utilisation is the default green→yellow→red @ 0–100. Error rate is inverted (low is good) over 0–5 %. Latency uses a two-stop blue→red @ 50–400 ms. CSAT inverts a green→red over 1–5 (high is good). Budget burn flips back: low = green, high = red over 0–120 %.
