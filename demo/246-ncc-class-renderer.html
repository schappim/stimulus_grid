246 — NCC building class

National Construction Code class. 1a = single dwelling, 2 = SOU apartments, 5 = office, 6 = shop, 9b = assembly. The class is the gatekeeper to which Part of the NCC applies, and which inspections are mandatory.

Site NCC class Compliance note

Multi-class sites (e.g. retail downstairs, residential upstairs) encode both classes on the site record. The chip shows the dominant one; the note column carries the secondary.
