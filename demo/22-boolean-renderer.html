22 — Boolean renderer

A visual upgrade on the plain text ✓ the type="boolean" path renders. Green-filled check for true, muted X for false (keeps the grid calm — opt into red via your own variant if you want it), and a dash for null / undefined / blank. Recognises the common truthy strings (true, "yes", "1", "on") so DB columns of mixed truthy representations don't need preprocessing.

Feature Enabled Beta Enterprise only Default Notes
Custom variants: the Enterprise only column is boolean({ falseStyle: 'hidden' }) — false renders as nothing instead of a muted X, perfect for "true is the noteworthy case" columns. The Default column is boolean({ nullLabel: 'N/A' }). Pass truthy: (v) => v === 'ACTIVE' for column-specific truthiness.
