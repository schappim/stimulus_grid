38 — Markdown renderer

Inline + block-level Markdown for description and notes columns. The parser is a tiny regex pass — no library, no bundle bloat — covering bold / italic / inline code / strikethrough / links / bullet + ordered lists. Cell values are HTML-escaped before parsing, so user-supplied <script> always renders as literal text.

Supported subset: **bold**, *italic*, `code`, ~~strike~~, [link](https://…), and - bullet / 1. ordered lists. Pass { inline: true } for headlines / chip text where lists and line-breaks aren't wanted.

Editing: double-click any cell to edit the raw markdown source. The Notes column wires up a custom <textarea> editor template so newlines survive a round-trip — Shift+Enter inserts a newline, Enter commits, Escape cancels.
