32 — Attachments renderer

Airtable-style attachments cell. The value is an array of { id, filename, url, content_type, byte_size, thumb_url? } objects. Image attachments render as inline thumbnails; non-images render as kind-tinted file icons. Click an image to open a keyboard-navigable lightbox carousel; click a file to open it in a new tab.

The editable column on the right opens an attachment editor popover on double-click (or via the + button): drag files onto the cell, paste from the clipboard, or browse — existing attachments get an × remove button. Up to N thumbnails show inline; overflow collapses into a +N chip that opens the lightbox.

Task Owner Status Files (read-only) Uploads (editable)
Try this:
  • Click any image thumbnail in the Files column → carousel opens; use ← / → to step through, Esc to close.
  • Click a PDF / doc icon → opens in a new tab.
  • Double-click a cell in Uploads, or click the dashed + button → editor popover opens.
  • Drag a file from your desktop onto an Uploads cell, or paste an image after focusing the dropzone.
  • Click × on any tile in the editor to remove that attachment.
