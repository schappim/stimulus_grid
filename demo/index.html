stimulus_grid

An HTML-first data grid for Stimulus.js. HTML is the source of truth — drop a data-controller="grid" on a table and you get sort, filter, selection, paging, editing, virtual scrolling, and a public API.

  • 02 — JSON data via data-value
  • 03 — Filtering (text / number / date)
  • 04 — Selection (single, multi, checkbox)

  • 06 — Inline cell editing
  • 07 — Custom cell renderer via <template>
  • 08 — Virtual scrolling (10,000 rows)
