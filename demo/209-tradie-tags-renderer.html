209 — Tradie job tags

A controlled vocabulary of multi-tags with operational meaning. Unlike generic coloured-tags (#41), these labels are rules: warranty = no charge, after-hours = OT loading, insurance = honour the auth-limit, defect-callback = must close out before invoicing. Reserving the vocabulary stops users inventing typo-variants ("warranty work", "warr", "WARRANTY!!!").

Job # Customer Tags Note

The tag column is rendered with data-bind-html so each row can carry its own multi-chip set. Pre-render the HTML once at load — it keeps the renderer template trivial and the chips stay sortable / filterable on the underlying tags array.
