291 — Offline / pending-sync per-row

Toggle offline mode, add a row — it sits in the grid as pending with an orange edge until the connection comes back. Toggle online and the row syncs (or fails, depending on a simulated server error every few attempts). Critical for vans in patchy reception that capture rows long before the next 4G handshake.

Job # Customer Tech Sync

Pending rows stay in the grid optimistically — the user keeps working. When the network returns the row's sync field flips to synced (or error) and the edge dot disappears.
