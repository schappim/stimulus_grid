52 — Timeline steps renderer

Order-status / pipeline columns where the value is one of an ordered set of steps. Past steps fill solid, the current step gets a halo, future steps stay hollow. Pass showLabels: true for the text labels under each dot.

Order Status (compact) Status (with labels) Customer
Editing: the Status columns are editable — type the step name (case-insensitive) or its 0-based index. The dots re-paint immediately. Try typing 2 or shipped in any cell.
