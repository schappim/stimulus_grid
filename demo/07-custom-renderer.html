07 — Custom cell renderers

A column with data-header-cell-cell-renderer-value="id" looks up a <template id="id"> and clones it for each cell. Descendant elements with data-bind="field" get text from the row, and data-bind-attr="attr" sets an attribute from the column value (great for CSS hooks like [data-sport]).
