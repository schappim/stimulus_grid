35 — Audio attachment renderer

Call-recording column for a CRM-style log. Each cell renders as a compact play-circle icon next to the filename; double-click the icon (or single-click) to open a popover with a play/pause toggle, a draggable scrub bar, current / total time, and ±10s skip buttons. The popover uses howler.js when present on window.Howl and falls back to the native <audio> element otherwise — same UI either way.

The other columns are pulled from the date renderers demo — datetime (when the call happened), duration (call length), and relative-time (last contact) — so you can see the renderer composing with the rest of the built-in library.

howler.js Loaded from cdnjs. Remove the script tag and the renderer transparently falls back to native <audio>.

Try this:
  • Double-click any Recording icon (or single-click) — the player popover opens anchored to the cell.
  • Click anywhere on the scrub bar to seek; drag the thumb to scrub continuously.
  • Use ← / → for 5s seeks while the scrub bar is focused (Shift = 30s), Home / End jump to start / end, Space plays / pauses.
  • Press Esc or click outside the popover to close it. Opening a second recording closes the first — only one player is active at a time.
  • Sort by Length or Last contact to see the recordings rearrange.
