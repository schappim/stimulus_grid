21 — Number renderers

Three formatters that round out the existing currency + percent: number for separated decimals, compact-number for "1.2K / 3.4M / 1.2B", and file-size for bytes → KiB / MiB / GiB (binary by default; pass { binary: false } for the decimal disk-marketing flavour). All three right-align with tabular numerals so columns of numbers line up at the decimal.

Account Balance Compact Storage used Storage (SI) API calls / mo (long) 3 dp
Custom variants: the three pre-registered renderers use sensible defaults. Register your own with any Intl.NumberFormat option — the "SI" storage column above is fileSize({ binary: false }), the "API calls / mo (long)" column is compactNumber({ compactDisplay: 'long' }), and the 3 dp column is number({ decimals: 3 }). Locales work too: number({ locale: 'de-DE' }) → 1.234.567,89.
