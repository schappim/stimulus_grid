201 — Headerless grid (bare rows)

A grid with no <thead> strip and no footer (no status bar, no pagination) — just rows. Useful for feed / inbox / activity-log UIs where each row is self-describing and a column-header bar would be noise. The column <th> is still declared so the grid knows the field; one scoped CSS rule (thead { display: none }) hides it.

Latest mail

The grid's column metadata still lives on the <th> — sort / filter / resize APIs work the same, you just can't click a header to invoke them (use gridApi.setSortModel(...) or a custom toolbar instead). Pair with cell-selection: false for a fully static, list-like presentation.
