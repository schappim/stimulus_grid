212 — Inspection result

Pass / Fail / Conditional pass — plus a re-inspection flag the certifier ticks when something needs another look. Pending means the inspection is booked but not yet attended. Editable so the supervisor can update the result from the van.

Job Type Result Re-inspect Inspected

The re-inspect column is a separate boolean so it survives editing the result independently. Once a row is fail AND re-inspect: true, the saved-view "Open re-inspections" catches it without further config.
