57 — BSB renderer (Australian Bank-State-Branch)

Six-digit Australian BSB formatted as XXX-XXX, with the bank name annotated from the first two digits. Invalid values render red so dodgy data jumps out instantly.

Payee BSB Account Amount
Composition: the demo pairs BSB with mask({ format: 'last4' }) for the account-number column (PCI-style — only show the last 4 digits) and currency({ currency: 'AUD' }) for the amount.
