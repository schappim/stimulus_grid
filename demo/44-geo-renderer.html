44 — Geo renderer (lat / lng)

Lat-lng coords with a "View on Maps" link. Decimal shows 33.8688, 151.2093; DMS shows the sexagesimal notation surveyors and aviation use. Tile thumbnails are opt-in via a staticMap(lat, lng) → url callback — wire it to your Mapbox / Google Static Maps / OSM provider.

Site Coordinates (decimal) Coordinates (DMS) With tile thumb
Input shapes accepted: [lat, lng], { lat, lng } (also { latitude, longitude } and { lat, lon }), or a "lat,lng" string. The tile thumbnail uses OSM static tiles via staticmap.io so the demo works without an API key — pin a real provider in production.
