34 — Address (AU) renderer

A formatted Australian street address with a colour-coded state badge. Double-click a cell to open a multi-field popover editor with address1, address2 (and an optional third line), suburb, state, postcode, and country — laid out for AU conventions.

Customer Email Shipping address Last order
How to use it: the value is an object — { address1, address2, address3, suburb, state, postcode, country }. Double-click any address cell to edit. The third address line only appears once you type into line 2 (or click "+ Add another line"). State changes are reflected immediately as a coloured badge. Listen for grid:cellValueChanged to persist edits to your server.
