290 — Saved-view chips (localStorage)

Preset filter views as chips. Selecting a chip applies the saved quick-filter to the grid. The active selection persists in localStorage so refreshing this page (or coming back tomorrow) restores the same view.

Job # Customer Tech Day Status Tags

Each preset writes its quick-filter through gridApi.setQuickFilter(); saved-view selection is keyed in localStorage under sg:saved-view. Custom user views add to the same dict and survive reloads.
