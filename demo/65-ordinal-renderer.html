65 — Ordinal renderer (1st / 2nd / 3rd / …)

English ordinal suffix via Intl.PluralRules({ type: 'ordinal' }). Other locales fall back to the bare number (ordinal indicators vary too much to encode generically).

The suffixes follow the standard 1st / 2nd / 3rd / Nth English rule via the platform's Intl.PluralRules ordinal selector — so 21st, 22nd, 23rd, 111th, etc. all come out right without a bespoke switch.
