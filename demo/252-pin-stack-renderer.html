252 — Pin stack

Cylinder pinning chart at-a-glance. Yellow = bottom pin (depth), purple = master wafer, grey = driver, cyan = spool, red = serrated. Hover the chambers for the per-chamber security pin profile.

Cylinder Pin stack Brand

The chart is descriptive, not a re-pin worksheet — the real worksheet lives in your MKS software. The intent here is to spot the cylinder in a register where the security pinning has been swapped out.
