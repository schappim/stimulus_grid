233 — Cost code / phase code

Hierarchical cost codes — Master Builders, NACE, or your own WBS. The first pair groups the family (preliminaries, demolition, frames, services, finishes, …) which is enough to colour-code the chip. P&L roll-ups happen on the code; the label is for humans.
