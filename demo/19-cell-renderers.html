19 — Built-in cell renderers

A renderer is a small function: ({value, row, col, td}) → HTMLElement | string. Ten built-ins ship pre-registered (email, url, phone, currency, percent, progress-bar, star-rating, tags, country-flag, abn, avatar), plus a statusPill builder for any badge-style status column. Reference them by name from data-header-cell-cell-renderer-value.

User Email Phone Country Website ABN LTV Onboarding Usage Rating Tags Subscription Fulfillment Channel Shipping
How it's wired: the ten plain renderers (no config) are pre-registered at import — just reference them by name. The four status columns (Subscription / Fulfillment / Channel / Shipping) use the statusPill(colorMap, iconMap?) builder; the registration block is at the top of the page script. Avatar reads from window.__sgUsers by default; here we feed a plain name string and let it fall back to initials.
