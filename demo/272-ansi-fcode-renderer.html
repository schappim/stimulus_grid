272 — Door function (ANSI F-code)

ANSI/BHMA A156.2 function codes are the shortest unambiguous way to describe what a lock does. F01 = passage (no lock), F04 = entry, F09 = storeroom (always locked outside, free egress). Architects spec by F-code; a locksmith confirms the function on site by trying the key, the egress, and the latch.

Door Function Hand

Function and hardware are independent — an F09 storeroom function can be implemented as a cylindrical lockset, a mortice lock, or an electric strike. The function is "what the user experiences", not "what's in the box".
