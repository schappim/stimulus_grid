70 — Select / dropdown editor

Fixed-list single-choice cell. Double-click any cell to pick a value from the popover. Options can be tinted via colorMap (palette name) or color per-option (raw CSS colour). Set clearable: true for a "(none)" row at the top.

JS-configured columns

Options come from renderers.select({ options }) registered in JS.
