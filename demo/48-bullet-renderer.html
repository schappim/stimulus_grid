48 — Bullet renderer

Stephen Few's bullet chart — qualitative bands behind a value bar and a vertical target tick. Use it when "current vs goal" is the column's job and a bare progress bar wouldn't capture the bands.

Rep Q1 quota Q2 quota Q3 (per-row target) Q3 (raw)
Per-row overrides: when each row carries its own target / bands, pass an object cell value: { value, target, ranges }. The Q3 column does this — the Q3 (raw) column shows the value half of the same object so you can sanity-check the bar position.
