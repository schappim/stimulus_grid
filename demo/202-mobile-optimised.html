202 — Mobile-optimised grid

The same grid, two layouts. On a wide screen you get a full table — name, plan, status, MRR, last seen — with normal pagination. On a narrow screen (≤ 640px, or use the toggle) the table collapses to a single tap-friendly card column and the pager is replaced by infinite scroll: as you near the bottom of the list, the next chunk of rows auto-loads. No horizontal scroll, no pinch-zoom, no iOS-zoom-on-focus.

How it works: a single matchMedia('(max-width: 640px)') listener flips data-mode on the grid and toggles column visibility via gridApi.setColumnVisible. The summary column uses a <template> renderer that composes name + email + status into one tap-friendly card.

Infinite scroll: in mobile mode the <nav.sg-pagination> is hidden and a scroll listener on .sg-body-viewport watches how close the user is to the bottom. When they get within 200 px of it, the page size grows by 20 — effectively appending the next chunk of rows to what's already on screen. Scroll position is preserved (existing rows aren't replaced), so scrolling back up just works. The search input is font-size: 16px to suppress iOS focus-zoom; rows are padded to ≥ 44 px for touch hit-area; the panel respects env(safe-area-inset-bottom) for iPhone home-indicator clearance.
