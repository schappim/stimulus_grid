41 — Coloured tags renderer

Sibling of tags: every chip can opt into a colour from the grid's palette via a per-value colorMap. Mirrors how Notion / Airtable colour multi-select fields. Unknown values fall back to defaultColor.

Task Priority Labels T-shirt
Palette: gray · red · orange · yellow · green · blue · indigo · purple · pink. Or pass any CSS colour as the map value — the chip auto-picks a readable text colour from the background's luminance.
