75 — Time picker editor

Editable sibling to the display-only time renderer. Double-click to open hour + minute (+ optional AM/PM) wheels. The wire format is always 24-hour HH:MM regardless of how it's shown.

Event Start (12h, 5-min step) End (12h, 15-min step) Cron tick (24h)
Double-click an hour/minute to commit immediately; or single-click to pre-select and press Set (or Enter).
