56 — IP address renderer

Monospace IPv4 / IPv6 with light validation. Invalid IPs strike through in red. Optional countryField reads a sibling 2-letter ISO code from the row and prepends a flag — handy for request-log columns where you already have a GeoIP lookup feeding the data.

Actor IP Country User-Agent
Validation: the IPv4 pattern enforces 0-255 per octet, so 256.1.2.3 strikes through. IPv6 accepts standard colon-hex with :: shorthand. Try editing a cell and typing not-an-ip to see the invalid-state rendering.
