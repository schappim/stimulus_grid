23 — Delta / change renderer

The dashboard staple: +12.5% green with an up arrow, -3.2% red with a down arrow, 0% muted with a right arrow. Pre-registered as a percent renderer; pass style: 'number' for raw deltas, style: 'currency' for money changes, or inverted: true for columns where positive is bad (churn, error rate).

Metric This week WoW MoM Δ revenue Δ churn
Variants: the Δ revenue column is delta({ style: 'currency' }); the Δ churn column is delta({ inverted: true }) — a decrease in churn is green, an increase is red. showSign: false hides the explicit + if it reads as visual noise in your context.
