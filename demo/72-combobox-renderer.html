72 — Combobox / autocomplete editor

Type-to-filter sibling of select. Double-click a cell to open the popover with a search input, type to filter the list, ↑/↓ moves highlight, Enter commits. With allowCustom: true Enter on an empty match commits the typed string verbatim — a free-form combobox.

User City Country Role (free-form)
Try typing into Country — narrow to a single option, Enter commits. In Role, type a value that isn't in the list — Enter still commits it because allowCustom: true.
