228 — Aged receivables bucket

Four-segment ageing bar — Current / 30+ / 60+ / 90+ days — plus a chip naming the worst bucket. The bar widths are proportional to dollars so a $20k 90+ row reads visibly worse than a $1k 90+ row.

Customer Current 30+ 60+ 90+ Ageing

Sort by Ageing — the underlying sort value is the worst-bucket bracket (0 = clean → 3 = 90+ days), then by dollars within that bucket.
