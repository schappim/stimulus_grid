293 — Sync-conflict pill

The row was edited locally AND on the server since the last sync. The pill names the conflicting field and offers Keep mine / Use theirs / Merge. Without an explicit resolution UI the user is one stale tab away from overwriting a colleague's edit silently.

Job # Customer Mine Server Status

The merge button is intentionally optional — for many fields (status, technician, hours) there's no sensible "average" and the user must pick a side. Merge shines for notes, tags, and other additive data.
